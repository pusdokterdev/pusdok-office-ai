# Scheduled task: Weekly brief

Use the Notion connector, in the AI Office workspace. Load the
**editorial-feature** skill (Journalist+Editor). Follow `docs/status-flow.md`.

Find tasks whose Type is **Weekly brief** and Status is **New** or **Go**.
If there is none for this week, create one: Task `Weekly brief <date>`,
Type `Weekly brief`, Status `New`, Data Level `3 Restricted`, Name permission `Not asked`.

## Status = New (first pass)

1. Collect this week's material: Inbox rows with **Processed** ticked and `Captured at` in the last 7 days, and Second Brain pages edited this week. Read their Abstracts first and open the full text only to check a quote.
2. Group them into 3 to 5 themes. List the gaps where outside context would help.
3. If web search is available, find up to 3 outside sources per gap (official, academic or reputable news), each with one line and a link. Write them under a heading **Outside sources**, set Status to **Gate 1**, and stop. If web search is not available, list the gaps as questions under **Outside sources** and continue to step 4 as if `Gate 1` were `Internal only`.

## Status = Go (after the Boss decided)

4. If the draft would name participants and `Name permission` is `Not asked`, set Status to **Name gate** and stop. Unless it is `Allowed`, use initials or "peserta A".
5. Write the Tulisan Feature in Bahasa Indonesia under a heading **Final**, as the last section: headline, lede, 3 to 5 sections, and a closing "Catatan untuk Pimpinan" section. Use only headings, paragraphs and bullet lists there, no tables. If `Gate 1` is `Internal only`, use no outside sources.
6. Check it against the skill's checklist, then set Status to **Awaiting Boss**.

Add one **Agent Log** row for the run. Never set Approved or Archived. Never delete anything.
