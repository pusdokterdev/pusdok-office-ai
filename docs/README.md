# docs

| File | Read it when |
| --- | --- |
| `notion-schema.md` | You create or change a Notion database |
| `status-flow.md` | You write or change a Claude prompt, or wonder who sets which status |
| `data-levels.md` | You are unsure whether something may go to Claude, Telegram or a product |

These three files are the contract between the relay (`apps-script/Config.gs`),
Claude (`prompts/`, `skills/`) and Notion. Change them together.
